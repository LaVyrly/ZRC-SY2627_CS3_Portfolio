1. What is/are the parent class/es of the Programmer class in the video? 

    * The parent class of the Programmer class is the Employee class. In the video's workplace hierarchy demonstration, Programmer is implemented as a subclass inheriting directly from Employee.

2. If you were to add a new role called Intern, where would you place it in the inheritance hierarchy? Why?

    * The Intern class should be placed as a child class or subclass inheriting from the Employee class. This is because an intern shares core employment attributes and behaviors with regular employees, while allowing for specialized features unique to an internship, such as a university affiliation or specific mentor assignments.
